# Sleep Infographic

This project uses the built-in R dataset `sleep` to investigate whether ten patients respond differently to two sleeping drugs.

## Requirements

- R
- tidyverse

## How to run

Open a terminal in the project folder and run:

```bash
Rscript "infographic.R (fre.20.nov).R" sleep_infographic.png
```

The script creates `sleep_infographic.png`, showing how each patient responded to the two sleeping drugs.

## Data

The analysis uses the built-in `sleep` dataset in R. No external data files are needed.
